One test: Appendix 5

anti-CCP for rheumatoid arthritis, 37 studies, bivariate GLMM

Cochrane Appendix 5, glmer in R (key lines of 70)

X$n1 <- X$TP+X$FN;  X$n0 <- X$FP+X$TN
X$true1 <- X$TP;    X$true0 <- X$TN
X$recordid <- 1:37
Y = reshape(X, direction="long", varying=list(
      c("n1","n0"), c("true1","true0")), timevar="sens",
      times=c(1,0), v.names=c("n","true"))
Y = Y[order(Y$id),];  Y$spec <- 1-Y$sens
MA_Y = glmer(cbind(true, n - true) ~ 0 + sens + spec +
             (0+sens + spec|Study.ID), data=Y,
             family=binomial, nAGQ=1)
ma_Y = summary(MA_Y)
lsens = ma_Y$coeff[1,1];  se.lsens = ma_Y$coeff[1,2]
Sens = c(lsens, lsens-qnorm(0.975)*se.lsens, ...)
plogis(Sens);  plogis(Spec)
DOR = exp(lsens+lspec)
se.logDOR = deltamethod(~ (x1+x2),
              mean=c(lsens,lspec), cov=ma_Y$vcov)
# ... LR+, LR- the same way

Two tests: Appendix 12

CT vs MRI for coronary artery disease, 5 studies that did both tests

Cochrane Appendix 12, glmer + lrtest (key lines of 130)

Y$seCT <- (Y$CT)*(Y$sens);  Y$seMRI <- (Y$MRI)*(Y$sens)
Y$spCT <- (Y$CT)*(Y$spec);  Y$spMRI <- (Y$MRI)*(Y$spec)
A = glmer(cbind(true, n-true) ~ 0 + sens + spec +
          (0+sens + spec|Study_ID), data=Y, family=binomial)
B = glmer(cbind(true, n-true) ~ 0 + seCT + seMRI + spCT +
          spMRI + (0+sens + spec|Study_ID), ...)
C = glmer(... ~ 0 + sens + spCT + spMRI + ...)
D = glmer(... ~ 0 + seCT + seMRI + spec + ...)
lrtest(A,B);  lrtest(B,C);  lrtest(B,D)
ma_CT  = glmer(..., data=Y.CT);  sespci(ma_CT)
ma_MRI = glmer(..., data=Y.MRI); sespci(ma_MRI)
sespci(B)
diff_Se = plogis(seCT) - plogis(seMRI)
se.diff_Se = deltamethod(~ (exp(x1)/(1+exp(x1))) -
               (exp(x2)/(1+exp(x2))), mean=..., cov=se_cov)

Why the 3rd decimal moves Model E is the same model in both. With 5 studies the fit sits on a boundary (singular random effects), where lme4's optimizer stops at a point that depends on the order of the two random-effect blocks. easydta's order reaches the higher log-likelihood. Models A–D, the default, are not affected.
Data: anti-CCP = the 37 studies of Cochrane Appendix 5 (anti_ccp1 + anti_ccp2); CT vs MRI = the 5 studies of the Appendix 12 data that evaluated both tests (schuetz).
