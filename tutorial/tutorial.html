easydta tutorial

From an Excel sheet to Cochrane-style diagnostic test accuracy plots in four steps

Excel sheet→ dta_fit_single() / dta_pairwise()→ dta_forest() · dta_sroc() · dta_funnel()
1

Prepare packages

install once, load every session
# install once
install.packages(c("remotes", "rstudioapi", "readxl"))
remotes::install_github("vanioljantunes/easydta")

# load every session
library(easydta)      # attaches ggplot2 too
library(rstudioapi)
library(readxl)

3

One test: fit and plot

dta_fit_single → forest, SROC, funnel
# a. bivariate binomial GLMM (Cochrane Appendix 5)
fit <- dta_fit_single(d, tp = "TP", fp = "FP",
                      fn = "FN", tn = "TN",
                      studlab = "studlab")
print(fit)            # Se, Sp, DOR, LR+, LR-, I2

# b. coupled sensitivity / specificity forest
dta_forest(fit)

# c. SROC with confidence + prediction regions, AUC
dta_sroc(fit, test.label = "anti-CCP2",
         outcome    = "rheumatoid arthritis",
         population = "adults")

# d. Deeks funnel + asymmetry test
dta_funnel(fit, test.label = "anti-CCP2",
           outcome = "rheumatoid arthritis",
           population = "adults")

# e. save for the paper
png(file.path(mwd, "forest_ccp2.png"),
    width = 1400, height = 1000, res = 150)
dta_forest(fit)
dev.off()
Studies with a zero cell dta_funnel() adds continuity = 0.5 to all four cells of that study before computing ln(DOR); the GLMM fit uses the raw counts.
4

Two tests: compare

dta_pairwise → side-by-side SROC + differences
# paired wide frame: .e = CT, .c = MRI
res <- dta_pairwise(schuetz, studlab = "studlab",
                    intervention.label = "CT",
                    control.label      = "MRI")
print(res)     # LR tests + Se/Sp differences

dta_sroc_pair(res,
              outcome    = "coronary artery disease",
              population = "adults with suspected CAD")

# per-arm plots: pick the arm by role
dta_forest(res, test = intervention)
dta_funnel(res, test = control)
Paired or not? Every study did both tests → one wide .e/.c frame into dta_pairwise(). Each study did only one test → stack the arms with a test column and use dta_compare_tests(rbind(anti_ccp1, anti_ccp2), test_var = "test").
Reading the table Effect size = index minus comparator (95% CI). Sens / Spec p-values are likelihood-ratio tests (Cochrane Appendix 12); the AUC interval comes from a parametric bootstrap.
Plot titlestest.label, outcome, population
Build the title "sROC of test to predict outcome in population". Same arguments on dta_sroc() and dta_funnel(); dta_sroc_pair() takes the arm names as labels.
Arm by roletest = intervention
On a pairwise result, intervention is the .e arm and control the .c arm. The arm name (CT, MRI) is looked up for you; bare word or string both work.
Variance structurevariance = "equal"
"equal" shares the between-study variances across tests (Cochrane model B, default). "unequal" gives each test its own (model E).
AUC intervalauc_ic = TRUE, B = 2000
Bootstrap draws for the AUC CI and the AUC difference in dta_sroc_pair(). auc_ic = FALSE skips it for a fast preview; dta_sroc() uses auc_ci.
